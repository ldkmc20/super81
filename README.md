# super81

파일 하단에 원하는 텍스트를 삽입하고, 입력한 DB 개수만큼 파일을 자동 생성하는 도구입니다.

## 구성 파일
- `appender_tool.py`: 실제 로직(텍스트 삽입 + DB 파일 생성)
- `run_tool.sh`: 실행용 스크립트(더블클릭/실행)

## 사용 방법
```bash
./run_tool.sh
```

실행 후 순서대로 입력하세요.
1. 수정할 대상 파일 경로
2. 파일 하단에 추가할 텍스트
3. 생성할 DB 개수
4. DB 파일 저장 디렉터리(기본값: `generated_dbs`)
5. 생성 파일 접두어(기본값: `db`)

예: DB 개수에 `10`을 입력하면 `db_1.txt` ~ `db_10.txt`가 생성됩니다.
